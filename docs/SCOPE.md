# 发布范围

包含正式三主题的网页、现有音频、分组启动器、网页生成程序、语音生成程序及必要输入。不含参与者答卷、Excel、照片、访谈、知情同意书、模型权重、服务器环境或账户信息。

项目原始材料没有被修改。为便于跨机器使用，发布副本中的路径、生成输出目录和校验入口做了调整，详见 CODE-CHANGES.md。

来源文本属于演示与生成输入，不是参与者研究数据。模板内嵌在网页生成器中，已包含。语音最终候选片段、自动拼接程序和原环境锁定仍未提供；现有音频可直接播放。

研究者确认现场手动切换并穿插提问，会打断参与者触摸操作。启动器不能替代现场日志或证明独立使用。尚未决定项目许可证，第三方来源和参考声音许可仍由维护者确认。
