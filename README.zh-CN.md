# AccessWiki

语音概览与无障碍证据网页：提供单人旁白、双人问答、来源回查，以及 Windows 分组测试启动器。

本包整理自已有实验 ZIP，并包含桌面上的无障碍来源页更新。**不包含参与者数据，不需要重新生成音频，也不需要模型或 API 密钥即可查看已有材料。**

## 快速开始

**最简单：完整解压后，双击 `Launch-AccessWiki.cmd`，按 1–6 选择组别。** 它从自身位置查找脚本，无需先切换终端目录。

也可以继续使用 PowerShell：

1. 在包含 `Start-AccessWiki.ps1` 的文件夹中打开 PowerShell。
2. 粘贴下面两行，只把 `G6` 改成需要的 `G1`–`G6`：

```powershell
$group = "G6"
powershell.exe -NoExit -NoProfile -ExecutionPolicy Bypass -File ".\Start-AccessWiki.ps1" -Group $group
```

这仅为本次 PowerShell 进程指定脚本运行策略，不修改系统的永久设置。如果组织策略禁止运行脚本，应遵循其规定。

3. 输入对应的测试编号；例如 G6 使用 P06 或 P12。这里只是加载预定顺序，不采集或上传答卷。
4. 菜单中 `1/2/3` 打开三轮材料，`4` 打开分配的错误核验材料，`5` 打开公交练习，`6` 打开医院来源页，`V` 检查绑定，`Q` 退出。终端面向研究人员，网页才是参与者界面。

| 组别 | 编号 | 三轮顺序 |
|---|---|---|
| G1 | P01 / P07 | 铁路 B1 → 医院 B2 → 退货 P |
| G2 | P02 / P08 | 铁路 B1 → 退货 P → 医院 B2 |
| G3 | P03 / P09 | 退货 B2 → 医院 B1 → 铁路 P |
| G4 | P04 / P10 | 退货 B2 → 铁路 P → 医院 B1 |
| G5 | P05 / P11 | 医院 P → 退货 B1 → 铁路 B2 |
| G6 | P06 / P12 | 医院 P → 铁路 B2 → 退货 B1 |

B1/B2/P 是原始文件和启动器名称，分别对应论文 M1/M2/M3：来源访问、单人旁白加证据页、双人问答加证据页。

## 只看网页和听音频

无需终端，双击根目录的 `index.html`，再进入铁路、医院或退货的材料。网页只提供浏览入口，不记录答案。分组材料调用使用 PowerShell 启动器；现场由研究者手动切换，菜单不代表实际播放日志。

GitHub 文件预览不会运行 HTML；请下载并解压后打开。需要在线演示时，再另行配置网页托管。

## 公开范围

包含程序脚本、网页、预生成音频与演示所需来源材料。不包含参与者 Excel、照片、答卷、录音、签署知情同意书或个人访谈。程序运行不依赖这些研究记录；本次不设参与者 `data/` 目录。

代码仓库目标：[InSAI-Lab/AccessWiki](https://github.com/InSAI-Lab/AccessWiki)。本包尚未上传。

## 与论文的对应和待补内容

研究者于 2026-09-26 补充确认：现场由研究者手动切换音频，以推进访谈进度；听完音频后还需提问等，过程中会打断参与者的触摸操作。因此，启动器菜单仅是材料调用工具，不能用默认菜单顺序重建现场实际播放时间线。本次不改写原有音频选择逻辑，也不把流程描述为自动连续播放或完全独立操作。该确认没有提供逐人逐轮的文件及时间日志。

论文系统部分写到用 Python 脚本与 HTML 模板生成 claim–evidence 页面。当前包包含输出网页、启动代码和两个正式生成程序；**正式网页生成 Python（含内嵌模板）、音频合成程序与 8 份 JSON 文本已合入；CosyVoice 环境版本和最终音频拼接过程仍待补充**，才能较完整地兑现代码公开说明。参与者原始数据无需为运行演示而提供。

详见 [运行说明](docs/RUNNING.md)、[材料与代码范围](docs/SCOPE.md)、[检查结果](docs/VALIDATION.md)。许可尚待项目作者确定；本次打包不为第三方来源和声音素材添加新许可。
